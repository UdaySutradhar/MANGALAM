## Mangalam HDPE Pipes - Product Page Implementation

This repository contains a **pixel-perfect**, responsive product page for Mangalam HDPE Pipes, built as part of a technical assessment. The project focuses on high-quality UI implementation, interactive elements, and performance optimization using **Vanilla HTML5, CSS3, and JavaScript**.

---

### ## Key Features

* **Pixel-Perfect Design:** Closely follows the provided Figma specifications for desktop, tablet, and mobile layouts.
* **Sticky Header:** An interactive header that appears smoothly when scrolling past the first fold and hides when scrolling back up.
* **Interactive Image Carousel:** Smooth transitions between product images with synchronized thumbnail navigation.
* **E-commerce Zoom Functionality:** Hovering over the main product image triggers a high-resolution zoomed preview, providing a detailed look at the material texture.
* **Custom Branding:** Custom-styled brand logos featuring integrated iconography and specific typography layouts.
* **Technical Specifications:** A clean, accessible data table presenting pipe dimensions and material properties.

---

### ## Tech Stack

* **HTML5:** Semantic markup for SEO and accessibility.
* **CSS3:** Custom Flexbox and Grid layouts, including advanced effects like SVG noise textures and custom cursor mapping.
* **JavaScript:** Vanilla JS for DOM manipulation, scroll event handling, and custom zoom logic—no external libraries or frameworks used.

---

### ## Installation & Usage

1. **Clone the repository:**
`git clone [https://github.com/UdaySutradhar/MANGALAM.git](https://github.com/UdaySutradhar/MANGALAM.git)`
2. **Open the project:**
Navigate to the project folder and open `index.html` in any modern web browser.
3. **Explore:**
* Scroll down to trigger the **Sticky Product Bar**.
* Hover over the main image to use the **Zoom Lens**.
* Click thumbnails to switch the active gallery view.



---

### ## Project Structure

* `index.html`: Contains the semantic structure of the page.
* `styles.css`: Contains all layout styles, responsive media queries, and animations.
* `script.js`: Handles interactive features like the sticky header, carousel, and zoom.
